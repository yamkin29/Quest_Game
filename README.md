# Quest Game

Quest Game is a small browser-based science-fiction text adventure.

After crash-landing on a mysterious planet, the player must explore an abandoned complex, solve puzzles, and find a way home. The world is explored through a terminal, and the story changes based on the entered commands and decisions.

## Features

- A branching story with victory and death outcomes
- Locations to explore, items to find, and puzzles to solve
- Russian and English languages
- Light and dark themes
- Responsive desktop and mobile interface

## Built with

React, TypeScript, Vite, and Mantine.

## Getting started

```bash
npm install
npm run dev
```
